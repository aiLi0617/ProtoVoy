- `ApiVoy` / `apivoy` was the previous product and technical name. Read-compat for env, headers, config dirs, CSS aliases, and storage keys has been removed; use ProtoVoy identifiers only.
- `Reqonaut` was an earlier product name; do not use it in user-facing surfaces going forward.
- `ApiLens` was an internal scaffolding codename only. Do not use it in user-facing surfaces, package names, or binaries.
